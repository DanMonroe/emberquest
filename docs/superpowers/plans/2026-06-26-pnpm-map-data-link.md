# pnpm + emberquest-map-data Local Link Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate `emberquest-map-data` to pnpm, point `emberquest` at the GitHub source for Netlify builds, and document the `pnpm link` workflow for local development.

**Architecture:** `emberquest-map-data` is a plain JS package (no ember-cli build tooling needed) whose `tiledata/` files are consumed via dynamic `import('emberquest-map-data/tiledata/<name>')` in the main app. The vestigial `addon/` and `app/` directories will be removed. `emberquest` will reference the package via `github:DanMonroe/emberquest-map-data` so Netlify can clone it at build time. Local development uses `pnpm link ../emberquest-map-data` to bypass the GitHub source.

**Tech Stack:** pnpm 10.34.4, Node 20.20.2 (Volta-pinned)

## Global Constraints

- Use `pnpm` (via mise shim at `/Users/dan.monroe/.local/share/mise/shims/pnpm`) — not npm, not the corepack/Volta pnpm shim
- Do not push to GitHub
- Do not change any game logic, map data files, or Ember source files

`emberquest-map-data` is resolved from `github:DanMonroe/emberquest-map-data` for Netlify builds.

```bash
# Use local emberquest-map-data (run from emberquest directory)
pnpm link ../emberquest-map-data

pnpm unlink emberquest-map-data && pnpm install
